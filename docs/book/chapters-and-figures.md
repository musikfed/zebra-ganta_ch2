## Инженерный стандарт иллюстраций (обязателен)

1. Никаких фото из поисковой выдачи, «заменителей» схем или декоративных миниатюр. Показывать только исходные SVG проекта, фотографии автора либо графики, восстановимые по исходным измерениям.
2. На каждой иллюстрации: русские подписи, единицы измерения, идентификатор опыта и статус (**эксперимент**, **условная схема**, **симуляция**, **заводские данные**).
3. Использовать единые шрифты с кириллицей, белый фон, контрастные линии, минимум цвета (синий — оборудование/связи, оранжевый — данные и ключевые области); макет проверять на уменьшении к печати A5.
4. Реальные точки и выбросы не удалять. Рис. 2.1 намеренно сохраняет аномальный первый отсчёт 19,90 МБ/с.
5. Название «Рис. 2.x» — **временный инвентарный номер** во второй части; окончательная нумерация по главам будет выполнена при верстке.
6. SVG — редактируемый мастер. Экспорт в PNG/PDF выполнять только после визуальной проверки текста и кириллицы; избегать растягивания низкого разрешения.
7. Для каждой главы в отдельном журнале указывать ссылку на исходный опыт, CSV/JSON, имя рисунка, подпись и ограничения. Не публиковать статистику, полученную только в симуляции, как показания HDD.

## Дополнение: сравнительный стенд USB 2.0 / USB 3.x

В главы 1, 2, 3 и 7 включить уточнение: исходный USB–SATA JMicron **152D:2338** фактически подключён в **High-Speed**, не SuperSpeed (USBView, 13.11.2026). Второе подключение — док-станция **ORICO 6139C3-EU-CR-BP**, кабель **USB-C ↔ USB-C** ноутбука Acer, независимый блок питания **12 В**. Это **описание оборудования**, не результаты USB 3.x. В главе 7 после получения реальных CSV сделать таблицу A/B по зонам LBA, медианам, разбросу и near/far. Иллюстрации с результатами USB 3.x создавать только из оригинальных измерений, не использовать предполагаемые числа и не считать разницу доказательством эффективности «Гантовой зебры».


13.11.2026: новый USBView для док-станции ORICO через USB-C (внешнее питание 12 В) показал VIA Labs `2109:0715`, фактическое **SuperSpeed 5 Гбит/с** и устройство Windows **UAS**. Это экспериментальный паспорт второго подключения (в отличие от JMicron High-Speed/BOT), **не измерение скорости HGST**. Дальнейшие рисунки — только после CSV нового опыта 004. См. протокол 004.
