## Ограничения

Это **наблюдаемая скорость чтения через Windows + USB**, а не заводская скорость магнитной поверхности, не физическая карта дорожек и не доказательство результата «Гантовой зебры». Не отключены кэши Windows и USB; реальная скорость USB-соединения HGST не подтверждена. Наличие двух AMD USB 3.10 хост-контроллеров со статусом OK не подтверждает USB 3.x у подключённого диска.

Числа в CSV представлены с точностью до **0,01 МБ/с**, как в присланном тексте. Поле `latency_s_derived_approx` вычислено обратно из округлённой скорости; **это не исходное измеренное время**. Использовать первичный `measurements.csv` с более точными временами после его отдельного импорта.

Для книги: рисунок по этим данным подписывать «Наблюдаемая скорость чтения HDD по диапазонам LBA через USB–SATA, опыт 002», с предупреждением о непроверенном режиме USB. Отрицательный или нулевой итог гипотезы допустим.
