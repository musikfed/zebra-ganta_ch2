# Опыт № 003 — «Цена одного перехода»: близкое и дальнее чтение

**Дата:** 12 ноября 2026 года. **Статус:** проведены две независимые серии на HGST; **предварительные результаты**, физическое время перемещения головок не измерено отдельно. Данные переданы автором в консольном выводе PowerShell. Первичные файлы `observations.csv` / `manifest.json` находятся на Acer, **в GitHub пока не импортированы**.

## Методика

Оборудование: Acer Swift 3 / Windows 11 Pro / Python 3.14.4 / HGST HTS725050B7E630, Disk 2, USB–SATA JMicron.

Команда:
```powershell
uv run python transitions.py --disk 2 --expect-model HTS725050B7E630 --expect-size 500106780160 --pairs 20 --seed 20261112
```

Программа перед каждой целевой операцией читает контрольный блок 4 КиБ по опорному LBA; затем целевой блок 4 КиБ вблизи (на расстоянии 2 МиБ) или вдали (другая область LBA). Порядок `near/far` в парах чередуется; результаты рассчитываются через `perf_counter_ns` на операции чтения Windows, не на физический seek.

## Два экспериментальных запуска (мс)

| Метрика | Серия 1 | Серия 2 |
|---|---:|---:|
| Медиана близкого чтения (`near`) | 10,8974 | 10,9594 |
| Медиана дальнего чтения (`far`) | 17,0894 | 17,1212 |
| Разность двух медиан (`far - near`) | 6,1920 | 6,1618 |
| Пар сравнений | 20 | 20 |
| Каталог оригинальных данных | `F:\zebra-ganta_ch2\results\20261112T185114Z-transitions` | `F:\zebra-ganta_ch2\results\20261112T185549Z-transitions` |

В каждой серии выполнено 20 пар × (опорное + целевое чтение для `near` и `far`) = 80 операций чтения по 4 КиБ; две серии — 160 операций. Дисковая запись не выполнялась. Автоматические тесты программы: **14 успешно пройденных** в приложенном пользователем выводе.

## Предварительное наблюдение

В обеих сериях медианное наблюдаемое время целевого чтения после дальнего перехода оказалось больше, чем после близкого; разность медиан примерно 6,2 мс. Из этого **нельзя вывести точное дополнительное время перемещения механизма головок**, а также выигрыш какого-либо алгоритма размещения.

Внимание: *разность двух медиан* не тождественна *медиане попарных разностей*. До импорта `observations.csv` не вычислены разброс, квартили, интервалы неопределённости, нестандартные выбросы и зависимость от порядка чтения. Две серии использовали одинаковый `seed`, а значит одинаковые LBA-точки. Это повторяемость протокола на тех же адресах, **не независимая проверка на новых позициях**.

## Что нужно проверить перед главой 4

1. Импортировать оба первичных `observations.csv` и `manifest.json` из каталогов `results`; сравнить их с выводом и зарегистрировать как оригиналы, а не ручной транскрипт.
2. Вычислить **попарные** разности и распределения по обоим режимам; оценить влияние порядка, опорных чтений и аномалий.
3. Повторить на **другом seed** и большем количестве пар, если состояние диска позволяет.
4. Отдельно определить фактический режим соединения USB и по возможности сравнить с другим интерфейсом.
5. Учесть разницу радиальных диапазонов: `near` и `far` измеряются в разных областях диска, поэтому нельзя изолировать только перемещение.
