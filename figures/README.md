## Правила воспроизводимости и подготовки глав

1. Исходные CSV/JSON/SVG, сформированные программой на Acer, остаются локально в `F:\zebra-ganta_ch2\results\20261112T180219Z`, пока автор не опубликует их явно. Рис. 2.1 создан по числам из консольного журнала; после передачи CSV его надо перепроверить автоматическим сравнением.
2. При переносе в книгу указывать дату, точную модель HDD, подключение USB–SATA JMicron, Windows 11, Python 3.14.4, 5 выборок, 3 повтора, объём 16 МиБ, единицы МБ/с (10^6 байт/с).
3. Графики реальных измерений не стилизовать так, чтобы скрывать выбросы: 19,90 МБ/с на первом отсчёте 5%-ной зоны обязательно сохраняется в данных и показан отдельным прогоном.
4. Схемы и графики всегда подписывать отдельно. Изображения класть в `figures/`; исходные замеры — в `results/` локально; утверждённые протоколы — в `docs/experiments/`.
5. SVG ориентирован на иллюстрации книги и отчётов; формулы, подписи и источники должны сохраняться читаемыми в A5 и на смартфоне.

## USB-контроллеры — 12.11.2026

Автор выполнил:

```powershell
Get-CimInstance Win32_USBController | Select-Object Name,Status | Format-Table -AutoSize
```

Результат: два контроллера «Расширяемый хост-контроллер AMD USB 3.10 — 1.10 (Майкрософт)», оба `OK`. **Это характеристика хост-контроллеров, не подтверждение, что HGST работает на скорости USB 3.x.** До установления скорости соединения гипотеза об ограничении USB 2.0 остаётся гипотезой.
